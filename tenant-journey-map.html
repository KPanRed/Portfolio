Key Research Insights
🎯
Selective attentionAssociates mentally filter out most of the UI, focusing only on their core workflow zones. Features outside this zone are effectively invisible — they don't know they exist.
🔁
Workaround cultureUsers have developed personal hacks to compensate for system failures — accidental VNC requests, wrong tab closures, and processing delays are accepted as normal.
😓
Trust deficitSystem unreliability (data loss, mid-task crashes) creates persistent anxiety. Associates work defensively rather than efficiently — always bracing for the next failure.
✂️
Minimalism preferenceAcross all sessions, associates consistently preferred less UI. Clutter is the #1 driver of frustration. Every extra element is perceived as a threat to focus, not a feature.

Pain Points
& Friction
⚠️Data load runtimes vary by source system — no consistent SLA, creating planning uncertainty
⚠️Multiple disconnected source systems require manual reconciliation before planning can begin
⚠️Approval workflows span multiple systems (YO/DA, Anaplan, SAP) — status visibility is fragmented
⚠️Investment case modeling and approval happen in separate tools with no native handoff confirmation
⚠️Contractors submit time through Fieldglass while FTEs use VzTime — creates reconciliation overhead
⚠️India FTE labor tracked separately from US FTE, requiring additional reconciliation steps
⚠️Delivery teams use JIRA for agile work but project financials live in SAP — no native connection
⚠️Time entry errors in CATS propagate into labor postings and Fixed Asset capitalization downstream
⚠️Reporting requires querying multiple BI tools (Looker, Tableau, Qlik) — no single source of truth for leadership
⚠️Adhoc reporting requests require manual data pulls because self-service BI lacks current data
✨
Opportunities
& Interventions
→Establish SLA agreements for data load pipelines; surface data freshness indicators to planners in Anaplan
→Consolidate source ingestion into CDL with standardized refresh cadences to reduce reconciliation burden
→Extend YO/DA to provide a unified approval status dashboard — single pane of glass across all workflow states
→Automate approval confirmation notifications back to Anaplan to eliminate manual status checks
→Unify contractor and FTE time capture into a single interface — consolidate Fieldglass and VzTime views in YO/DA
→Automate SOW milestone tracking alerts to resource managers before budget variance occurs
→Build JIRA-to-SAP financial bridge through YO/DA — delivery progress linked to budget consumption in real time
→Introduce time entry validation rules in CATS to prevent downstream capitalization errors before settlement
→Rationalize BI tool landscape — establish Looker as the primary reporting layer with governed data models
→Implement automated budget vs. actual alerting for GTS POCs so exceptions surface proactively
